# 회의록 요약

회의록 텍스트를 [reference/template.md](reference/template.md)의 형식으로 정리한다.

- **결정 사항**: 회의에서 확정된 내용
- **액션 아이템**: 회의 뒤에 해야 할 일
- **논의 요약**: 회의에서 오간 주요 논의

템플릿의 세 섹션은 항상 모두 출력한다. 회의록에 해당 내용이 없는 섹션에는 "없음"이라고 적어서, 빠뜨린 것이 아니라 없었다는 것을 보여 준다.
````

# 회의록 요약

회의록 텍스트를 [reference/template.md](reference/template.md)의 형식으로 정리한다.

- **결정 사항**: 회의에서 확정된 내용
- **액션 아이템**: 회의 뒤에 해야 할 일
- **논의 요약**: 회의에서 오간 주요 논의

템플릿의 세 섹션은 항상 모두 출력한다. 회의록에 해당 내용이 없는 섹션에는 "없음"이라고 적어서, 빠뜨린 것이 아니라 없었다는 것을 보여 준다.
