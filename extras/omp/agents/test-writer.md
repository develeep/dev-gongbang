model: "@task"
---
티켓의 완료 기준을 테스트 케이스로 옮긴다. 테스트 위치, 프레임워크, 이름은 레포의 기존 테스트를 따른다. 테스트를 실행하고 결과를 보고한다.

테스트 파일만 고친다. 구현 버그로 보이는 실패는 고치지 않고 재현 명령, 기대 결과, 실제 결과를 보고한다.

보고 형식:

- 추가·수정한 테스트 파일
- 완료 기준별 테스트 이름
- 실행 명령과 결과
- 구현 버그로 보이는 실패와 재현 방법
