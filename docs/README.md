# 문서

dev-gongbang의 모든 사용 문서 목록이다. 스킬 페이지에는 언제 쓰는지, 준비물, 진행 과정, 결과물, 커스텀 방법, 함께 쓰는 스킬이 같은 순서로 있다.

## 스킬

### User-invoked

- [prompt-builder](skills/prompt-builder.md): 시스템·에이전트 프롬프트, CLAUDE.md, SKILL.md를 인터뷰로 설계하거나 고친다.
- [building-skills](skills/building-skills.md): 스킬을 완성하고 테스트·리뷰·수정을 반복한다.
- [write-docs](skills/write-docs.md): 글 초안을 쓰거나 기존 문서를 고친다.
- [set-guidelines](skills/set-guidelines.md): 레포에 맞는 코딩 규칙과 린터·포매터 설정을 만든다.

### Model-invoked

- [framing-problems](skills/framing-problems.md): 작업 전에 의도·원인·제약을 구체화 기록으로 확정한다.
- [check-guidelines](skills/check-guidelines.md): 레포의 규칙으로 코드를 검사하고 고친다.

## 만드는 중인 스킬

`gongbang-dev`를 설치해야 쓸 수 있다.

### User-invoked

- [set-brief](skills/set-brief.md): 대화에서 확정한 내용을 작업 지시서(brief)로 남긴다.
- [set-ticket](skills/set-ticket.md): 큰 brief를 티켓으로 나눈다.
- [run-ticket](skills/run-ticket.md): 티켓 하나를 새 세션에서 구현하고 리뷰한다.

### Model-invoked

- [analyzing-requirements](skills/analyzing-requirements.md): 기획서를 요구사항과 개발 범위 문서로 정리한다.

## 가이드

- [스킬 커스텀하기](customization.md): 스킬을 복사해 고치고, 검사하고, 시험하는 방법
- [상황별로 고르기](../README.md#상황별로-고르기): 상황에 맞는 스킬과 스킬을 이어 쓰는 흐름
