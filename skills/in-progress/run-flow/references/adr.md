# ADR 남기기

2단계와 6단계에서 결정 중 세 조건을 모두 만족하는 것만 ADR 후보로 보여 주고, 사용자가 고른 것만 남긴다. 조건: 되돌리기 어렵다, 맥락 없이 보면 왜 그렇게 했는지 의아하다, 실제 대안 사이에서 이유를 갖고 골랐다. 하나라도 아니면 후보로 올리지 않는다. 후보가 없으면 묻지 않고 넘어간다.

저장 위치는 레포에 ADR 폴더와 형식이 있으면 그것을, 없으면 `docs/adr/NNNN-<slug>.md`(NNNN은 기존 번호 다음)를 쓰고, 상태 파일 `## 결과물`의 ADR에 링크를 적는다. ADR에는 `- 작성일:` 줄을 쓰지 않는다. brief로 잘못 잡힌다. set-ticket이 저장소의 ADR을 읽고 따르므로 2단계에서 남긴 ADR은 티켓에 반영된다.

```markdown
# NNNN. <결정 한 줄>

- 날짜: YYYY-MM-DD
- 상태: 채택
- 흐름: <상태 파일 경로>

## 맥락
## 결정
## 고려한 대안
## 결과
```
